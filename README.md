## TP4 - Estilado Avanzado y Responsive Design con CSS3

Este trabajo práctico amplía los estilos del sitio mediante técnicas de CSS3, posicionamiento y diseño adaptable a diferentes tamaños de pantalla.

### Características implementadas

- Importación de la fuente Montserrat desde Google Fonts.
- Definición de una paleta cromática personalizada mediante valores HSL.
- Estilizado de formularios, campos de entrada y tablas.
- Encabezado fijo mediante `position: fixed`.
- Contenido biográfico con desplazamiento vertical y título adhesivo mediante `position: sticky`.
- Logo institucional con animación de rotación al pasar el cursor.
- Botón flotante para volver al inicio de cada página.
- Diseño responsive mediante media queries para pantallas de hasta 768 píxeles.
- Adaptación de la navegación, los formularios, las imágenes y las tablas a dispositivos pequeños.

### Tecnologías utilizadas

- HTML5
- CSS3
- Google Fonts
- Git y GitHub
